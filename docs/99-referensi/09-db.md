# Referensi: `Selvi\Database\DB`

Facade statis pembuat builder. Kelas ini tidak menyimpan state: setiap
pemanggilan membuat objek baru dengan koneksi yang diminta.

Aturan yang berlaku:

- Nama koneksi kosong (`''`) berarti koneksi default, yaitu
  `Manager::default()` (koneksi pertama yang terdaftar).
- `connection()` mengembalikan `QueryBuilder`, **bukan** `IConnection`. Koneksi
  sebenarnya diambil lewat `Manager::get()`.
- Nama koneksi baru di-resolve saat builder dipakai (`getSql()`, `get()`, dst.).
  Bila belum ada koneksi terdaftar, pemakaian builder melempar
  `RuntimeException: Koneksi database belum diatur.`

Pemakaian ada di [koneksi](../02-database/01-koneksi.md) dan
[skema tabel](../02-database/02-skema-tabel.md).

## Method statis

### `connection($name)`

| Parameter | Tipe | Default | Keterangan |
|---|---|---|---|
| `$name` | `string` | `''` | nama koneksi; kosong berarti koneksi default |

**Kembalian:** `Selvi\Database\Builder\DML\QueryBuilder`. Return type tidak
dideklarasikan di source.

### `table($table)`

| Parameter | Tipe | Default | Keterangan |
|---|---|---|---|
| `$table` | `string` | wajib | nama tabel yang akan di-query |

**Kembalian:** `QueryBuilder` dengan tabel sudah diatur.

### `schema($connection)`

| Parameter | Tipe | Default | Keterangan |
|---|---|---|---|
| `$connection` | `string` | `''` | nama koneksi; kosong berarti koneksi default |

**Kembalian:** `Selvi\Database\Builder\DDL\SchemaBuilder`.

## Sumber

- `src/Database/DB.php`
- `src/Database/Builder/DML/QueryBuilder.php` — resolusi koneksi default
- `src/Database/Builder/DDL/SchemaBuilder.php` — target `schema()`
- `tests/02.01-koneksi/index.php` dan `tests/02.02-skema-tabel/index.php` —
  aplikasi uji

## Status verifikasi

Diuji 29 Oktober 2026:

| Kasus | Hasil |
|---|---|
| `DB::table('kontak')->select(...)->getSql()` tanpa nama koneksi | SQL memakai koneksi default |
| `DB::schema('main')` untuk `create()`/`alter()`/`drop()` | seluruh operasi DDL berhasil |
| `DB::connection('main')` | mengembalikan `QueryBuilder`, bukan koneksi |

Belum diuji: `RuntimeException` ketika belum ada koneksi terdaftar. Perilaku itu
disimpulkan dari `QueryBuilder::connection()`.
